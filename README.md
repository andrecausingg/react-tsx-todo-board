### Clone repository

git clone https://github.com/andrecausingg/react-tsx-todo-board.git

### Change path

cd react-tsx-todo-board

### Fetch branch

git fetch

### Checkout branch

git checkout release

### Create .env

.env

### API | Add variable in .env

VITE_BACKEND_URL=http://localhost:8001/api

### Authenticated indicator | Add variable in .env

VITE_AUTHENTICATED=authenticated

### Start up Docker containers

docker-compose up -d
